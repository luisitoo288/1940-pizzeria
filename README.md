# 1940 La Pizzeria — Menú Digital

Menú digital interactivo para **1940 La Pizzeria**, Cartagena de Indias 🍕

## Archivos
- `index.html` — Estructura HTML
- `styles.css` — Estilos CSS (sidebar, animaciones, redes, contacto)
- `script.js` — Lógica JS (física mozzarella, scroll reveal, filtros)

## Características
- 🧀 Sidebar con animación de queso mozzarella con física real
- 🎬 Animaciones de scroll reveal por sección
- 📱 Secciones de Redes Sociales y Contacto
- 🍕 Menú completo: 25 clásicas + 11 especiales + bordes y adiciones
